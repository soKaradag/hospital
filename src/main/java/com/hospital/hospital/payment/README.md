# Payment Domain

Bu domain ödeme süreçlerini yönetir.

## Amaç
- Muayene veya işlem sonrası ödeme kaydı tutmak
- Ödeme yöntemi ve ödeme durumunu izlemek
- Temel finansal akışı Faz 1 seviyesinde başlatmak

## Faz 1 Kapsamı
- Payment entity
- Payment repository
- Payment service
- Payment controller
- Payment DTO yapıları
