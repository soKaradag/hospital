# Encounter Domain

Bu domain muayene veya ziyaret kaydını yönetir.

## Amaç
- Gerçekleşen hasta ziyareti kaydını tutmak
- Şikayet, değerlendirme ve muayene notlarını çekirdek klinik kayıt olarak saklamak
- Randevudan muayeneye geçişi izlemek
- Sonraki fazlarda reçete, laboratuvar ve tanı detaylarının bağlanacağı çekirdek alanı oluşturmak

## Faz 1 Kapsamı
- Encounter entity
- Encounter repository
- Encounter service
- Encounter controller
- Encounter DTO yapıları
